2014年の設立以来、
マーケティングサービス事業を主軸に
展開を続けてきた株式会社Canvas。

事業拡大と変化し続ける時代に合わせ、ここに新たな取り組みを表明いたします。

Project A

企業復興支援
プロジェクト

飽和化する情報社会の中、良質なサービスや商品が単純に認知・普及する時代ではなくなりました。

弊社では、様々な業種における事業拡大へ向けてソリューション開発を行っています。提携先の選定、競合分析・市場調査などのコンサルティングサービスをご提供いたします。

Project B

経営者育成
プロジェクト

少子化と超高齢社会における年金制度への不安、止まらない失業率の上昇、そしてコロナ禍。解決されないままの課題を抱える日本社会において、「雇われる側」に立つ人材が窮地に立たされています。

弊社では、数多くの業界で事業復興を成し遂げてきたノウハウを活かし、次代を担うリーダーとなりうる人材の育成に努めます。

Features

経営者育成プロジェクトの特徴

本部と取引のある事業を使用して運営できる

実績と信頼のある企業と取引ができるので、独立後も早期に高い売上が見込めます。

本部の組織をそのままに事業を展開できる

経営者を育成するまでの過程には、組織としての運用が必須です。その統率力を最大限に発揮するため、組織全体での独立を公認しています。

独立時の資金調達は不要

独立後の屋号や開業場所もすべて自由。継続して共有するのは、ノウハウや市況感といった互いに有益になるものだけです。2017年以降、独立した企業での倒産はありません。
